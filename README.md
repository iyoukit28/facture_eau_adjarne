# نظام إدارة فواتير الماء — جمعية أدجارن للتنمية والتواصل

تطبيق ويب تفاعلي متكامل لإدارة وحساب واصدار فواتير استهلاك الماء لجمعية أدجارن للتنمية والتواصل. يتميز التطبيق بواجهة مستخدم عربية حديثة ومتجاوبة تعمل مباشرة عبر المتصفح بدون الحاجة لخوادم معقدة.

## المميزات الرئيسية
- **حساب الاستهلاك التلقائي**: إدخال قراءات العداد السابقة والحالية وحساب قيمة الفاتورة فورياً.
- **إحصائيات ورسوم بيانية**: عرض الرسوم البيانية للاستهلاك الشهري والفصلي باستخدام Chart.js.
- **طباعة الفواتير**: تصميم مخصص ومحسن للطباعة (Print-friendly) لإصدار الفواتير الورقية مباشرة للمشتركين.
- **الواجهة المتجاوبة**: تصميم حديث يدعم الهواتف المحمولة والحواسيب مع دعم كامل للغة العربية (RTL).

## طريقة الاستخدام
يمكن فتح الملف `index.html` (أو `فواتير-الماء.html`) مباشرة على أي متصفح ويب، أو تصفح الموقع عبر **GitHub Pages**.
